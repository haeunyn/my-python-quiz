

# 파이썬 퀴즈 게임 프로젝트

## 1. 프로젝트 개요
본 프로젝트는 파이썬을 활용하여 퀴즈를 풀고, 추가하고, 관리할 수 있는 종합 퀴즈 게임 프로그램 개발을 목표로 하였습니다. 또한, Git과 GitHub를 활용하여 버전 관리 및 협업 프로세스를 학습하고 적용하였습니다.

## 2. 미션 수행 결과

### 2.1 기본 미션 (5개 항목 완료)
1. **메뉴 시스템**: `while` 루프를 기반으로 문제 풀기, 추가, 목록, 점수 확인 메뉴 구현.
2. **문제 풀기**: 객관식(A, B, C, D) 인터페이스를 통한 퀴즈 진행 기능.
3. **문제 추가**: 사용자로부터 질문, 보기, 정답, 카테고리를 입력받아 실시간 반영.
4. **문제 목록**: 현재 저장된 모든 퀴즈의 질문과 정답을 리스트 형태로 출력.
5. **점수 기록**: 정답 시 점수를 부여하고, 누적 점수를 관리하는 기능.

### 2.2 보너스 미션 (5개 항목 완료)
1. **랜덤 출제**: `random.sample`을 활용하여 매번 다른 순서로 문제 출제.
2. **문제 수 선택**: 게임 시작 전 사용자가 원하는 문항 수를 설정하는 기능.
3. **힌트 기능**: 힌트 보기 기능을 제공하며, 사용 시 점수가 감점되는 페널티 로직 적용.
4. **문제 삭제**: 특정 번호의 문제를 선택하여 삭제할 수 있는 관리자 기능.
5. **히스토리 저장**: 과거 게임의 날짜와 점수를 기록하여 누적 히스토리 관리.

## 3. 기술적 구현 상세
- **객체지향 프로그래밍(OOP)**: `Question` 클래스로 데이터를 구조화하고, `QuizGame` 클래스로 전체 로직을 캡슐화하여 설계.
- **데이터 영속성**: `json` 라이브러리를 사용해 `state.json` 파일에 데이터를 저장. UTF-8 인코딩을 적용하여 한글 깨짐 방지.
- **예외 처리**: 
    - `KeyboardInterrupt` 및 `EOFError` 처리를 통해 비정상 종료 방지.
    - 잘못된 메뉴 선택 및 숫자 입력 오류(`ValueError`)에 대한 방어 코드 작성.

## 4. Git 및 버전 관리 현황
- **Git 명령어 활용**: `git init`, `add`, `commit`, `push`, `pull`, `checkout`, `branch`, `merge` 등 7종 이상의 핵심 명령어 숙달.
- **커밋 기록**: 기능 단위로 세분화하여 **10개 이상의 의미 있는 커밋**을 수행.
- **GitHub 배포**: 원격 저장소를 생성하고 로컬 프로젝트를 성공적으로 업로드 및 동기화.

## 5. 문제 해결 경험 (Troubleshooting)
- **문제**: 터미널 환경에서 최종 코드 실행 시 예기치 못한 문법 에러 발생.
- **해결**: 리눅스 터미널의 `nano` 편집기를 사용하여 즉석에서 코드를 수정하고 디버깅함.
- **성과**: 수정된 코드를 다시 Git에 커밋하고 GitHub에 최종 반영함으로써, 실제 개발 환경에서의 문제 해결 능력을 배양함.

## 6. 최종 소감
파이썬의 기초 문법부터 클래스 설계, 파일 입출력, 그리고 실무 필수 도구인 Git 활용법까지 프로젝트 전 과정을 직접 수행하며 개발 프로세스 전반에 대한 이해도를 높일 수 있었습니다. 특히 보너스 미션 5개를 모두 구현하며 논리적 사고력을 키우는 계기가 되었습니다.
